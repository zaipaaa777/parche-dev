## Decisiones que tomé

- Explica al menos tres decisiones: 
- usar <section> en vez de <div> para los bloques, section para dividir las partes principales
  de la pagina y el div para agrupar elementos.
- usar ol o ul,el ol lo utilice para listas ordenadas y el ul para listas que no tenian un 
orden o paso a seguir
- usar <input type="email"> en vez de <input type="text">, utilice en algunas ocasiones
el <input type="email"> porque era el formate correcto que redirige al correo.

##- después del signo aparecen los datos enviados por el formulario con GET.

##- espacios: aparecen como + en este formato de formulario. Por ejemplo, andres+leonardo     representa andres leonardo.
- tildes: normalmente aparecen codificadas mediante secuencias como %C3%A1
- arroba : aparece como %40. Por eso, 1andresrojas0%40gmail.com representa 1andresrojas0@gmail.com.

##- los campos vacíos normalmente no aparecen en la URL cuando se envía un formulario mediante GET.

##- un formulario que contiene contraseñas debe utilizar method="post" porque el método GET agrega los datos a la URL, dejándolos visibles en la barra de direcciones del navegador.
